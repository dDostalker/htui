# 教程 2：实现静态终端

默认情况下每次渲染都是交互式的（事件、脚本、命中测试全部启用）。如果你的
页面是纯展示型的，可以关掉事件系统，得到一个更轻量的静态渲染。

## 关闭事件系统

```rust
use htui::{Config, Session};

fn main() {
    let mut config = Config::default();
    config.events = false; // 静态渲染：无脚本线程、无命中测试、无事件

    let mut session = Session::new();
    session.set_config(config);
    session.render(
        r#"
        <h1>系统信息</h1>
        <table>
          <tr><td>主机名</td><td>dev-box</td></tr>
          <tr><td>内核</td><td>Windows</td></tr>
        </table>
        "#,
        "",
    );
}
```

`events = false` 时：

- 不启动脚本线程与命中测试线程，宿主函数不会被注入；
- 页面内的 `<script>` 不会执行、`on*` 属性不生效；
- 阻塞型宿主函数无从谈起——根本没有事件循环。

## 其余渲染配置

`Config` 的全部字段（`session.config_mut()` 可直接修改）：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `zoom` | `1.0` | 初始缩放（用户仍可在运行中用 `Ctrl` 键缩放，这只是种子值） |
| `events` | `true` | 是否启用 JS 事件 / 脚本线程 |
| `frame_gap` | `16ms` | 渲染线程两帧之间的最小间隔（~60fps 上限），防止快速滚动灌满终端输出管道 |
| `copy_flow` | `true` | 左键拖选的流式文本选择 + `Ctrl+C` 复制 |
| `copy_block` | `true` | 右键拖选的矩形块选择 + `Ctrl+C` 复制（vim / tmux 风格） |

## 会话级 CSS

`render` 的第二个参数是会话级 CSS，与文档内 `<style>` 叠加生效，优先级与
浏览器一致（后声明胜出）：

```rust
session.render(html, "p { line-height: 2 }");
```

适合在不改动 HTML 的前提下注入全局主题。
