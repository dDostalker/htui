# 教程 3.0：资源层概念

htui 中的文档永远不会直接访问文件系统或网络。页面能看到的一切外部资源——
`<script src>`、`<link rel="stylesheet" href>`、`<img src>` 以及 JS 的
`fetch()`——都通过**资源层**解析。

## mem:// 内存注册表

资源层是一个按路径索引的内存字节表。每个 `Session` 拥有一个私有注册表，
宿主通过 `register` 把字节注册进去，文档按路径读取：

```rust
let mut session = htui::Session::new();
session.register("app.js", b"console.log('loaded')".to_vec())?;
session.render(r#"<script src="app.js"></script>"#, "");
```

关键性质：

- **会话隔离**：注册表归会话所有，并行渲染的两个会话互不可见、互不污染；
- **无 IO**：注册与读取都是纯内存操作，不存在文件路径、URL 或网络请求；
- **前缀可选**：`register("app.js", …)` 与 `register("mem://app.js", …)`
  等价，页面里写 `src="app.js"` 或 `src="mem://app.js"` 都能命中；
- **相对路径**：文档若有 `<base href="mem://app/">`，页面内的
  `img/pic.png` 会解析到 `mem://app/img/pic.png`。

## 谁在用资源层

| 引用方式 | 用途 |
| --- | --- |
| `<script src="…">` | 加载页面脚本 |
| `<link rel="stylesheet" href="…">` | 加载外部样式表 |
| `<img src="…">` | 图片（PNG / JPEG / WebP / SVG） |
| JS `fetch(url)` | 返回真 `Promise`，经微任务事件循环 settle |

具体注册与读取操作见 [3.1资源的注册和读取](3.1资源的注册和读取.md)。

## 错误语义

读取未注册的路径返回 `MemNotFound` 错误：

- `<img>` 渲染为加载失败（错误经 `log` 记录，不崩溃）；
- `<script src>` / `<link href>` 解析失败仅告警，页面继续；
- `fetch` 将 Promise reject，页面可用 `.catch()` 处理——与浏览器一致。
