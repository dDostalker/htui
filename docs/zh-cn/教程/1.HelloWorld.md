# 教程 1：HelloWorld

本教程带你用 htui 渲染第一个终端页面。全程只需要一个 `Cargo.toml` 依赖和一个
`main.rs`。

## 添加依赖

```toml
[dependencies]
htui = "0.1"
```

## 第一个页面

```rust
use htui::Session;

fn main() {
    let mut session = Session::new();
    session.render(
        r#"
        <style>
          h1 { color: steelblue; }
          .tip { color: gray; }
        </style>
        <h1>Hello, htui</h1>
        <p class="tip">这是一段纯 HTML + CSS，直接渲染在你的终端里。</p>
        <p>按 <b>Esc</b> 退出。</p>
        "#,
        "",
    );
}
```

运行 `cargo run`，你会看到带颜色的标题与正文。`render` 的第二个参数是额外的
会话级 CSS（与文档内 `<style>` 叠加），这里传空即可。

## 说明

- `Session` 是渲染会话的入口：内部持有一个会话私有的 `mem://` 资源注册表和
  渲染配置（见 [3.0资源](3.0资源.md) 与 [2.实现静态终端](2.实现静态终端.md)）。
- `Session::render(html, css)` 是阻塞调用：它启动输入循环、渲染线程与脚本
  线程，直到用户按 `Esc` 退出才返回。
- 页面可以是完整的 `<html>` 文档，也可以像上面这样直接写片段——引擎会补全
  文档结构。
