# 教程 3.1：资源的注册和读取

概念见 [3.0资源](3.0资源.md)。本篇是操作手册。

## 注册与注销

```rust
use htui::{CssSource, HtmlSource, JsSource, Session};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut session = Session::new();

    // 注册字节（mem:// 前缀可省略；重复注册同一键 = 替换）
    session.register("app.js", include_bytes!("app.js").to_vec())?;
    session.register("mem://style.css", b"p { color: teal }".to_vec())?;
    session.register("logo.png", std::fs::read("assets/logo.png")?)?;

    // 注销，返回该键是否存在
    let existed = session.unregister("app.js");

    session.render(
        r#"
        <link rel="stylesheet" href="style.css">
        <img src="mem://logo.png">
        "#,
        "",
    );
    Ok(())
}
```

注意：注册路径为空字符串是唯一的注册错误（`ResourceError::EmptyPath`）。

## 直接读取

宿主侧也可以读回注册的字节（例如做校验或注入到别的会话）：

```rust
let bytes: std::sync::Arc<Vec<u8>> = session.load("app.js")?;
```

## 页面读取：fetch

JS 侧 `fetch` 返回真 `Promise`，注册表读取即时完成后经微任务事件循环
settle，`.then` / `await` 链照常工作：

```html
<script>
  fetch('mem://app.json')
    .then(function (r) { return r.text(); })
    .then(function (t) {
      document.getElementById('out').textContent = t;
    })
    .catch(function (e) {
      document.getElementById('out').textContent = 'load failed';
    });
</script>
```

## 完整示例：脚本 + 样式 + 图片

```rust
use htui::{CssSource, HtmlSource, JsSource, Session};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut session = Session::new();
    session.register("style.css", b"h1 { color: steelblue }".to_vec())?;
    session.register(
        "app.js",
        b"document.getElementById('out').textContent = 'from app.js';".to_vec(),
    )?;
    session.register("logo.png", std::fs::read("assets/logo.png")?)?;

    let html = HtmlSource::inline(
        r#"
        <link rel="stylesheet" href="style.css">
        <h1>资源层演示</h1>
        <img src="logo.png">
        <p id="out"></p>
        <script src="app.js"></script>
        "#,
    );
    session.render(
        &html,
        &CssSource::inline(""),
        &JsSource::inline("console.log('resource page loaded')"),
    );
    Ok(())
}
```

## 与库代码的关系

`Session::registry()` 暴露会话注册表；`Session::with_registry(f)` 把它安装到
当前线程，供手动驱动渲染管线的高级用法（如 headless 预览）使用。普通应用
只需要 `register` / `render`。
