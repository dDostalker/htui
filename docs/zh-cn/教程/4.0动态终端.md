# 教程 4.0：动态终端

htui 的事件系统与浏览器语义对齐：页面用 `on*` 属性或 `addEventListener`
声明行为，终端的鼠标 / 键盘事件经命中测试后沿 DOM 祖先链冒泡派发。

## 事件属性

```html
<button onclick="buy()">购买</button>
<div onmouseover="highlight()" onmouseout="unhighlight()">悬停我</div>
```

属性值按浏览器语义编译为 `function (event) { <body> }`：裸标识符只求值不调用
（`onclick="buy"` 不执行），`buy()` 才调用——与浏览器完全一致。

## addEventListener

```html
<script>
  document.getElementById('btn').addEventListener('click', function (event) {
    event.stopPropagation();       // 阻止冒泡
    document.getElementById('out').textContent = 'clicked';
  });
</script>
```

## 支持的事件类型

| 事件 | 触发时机 |
| --- | --- |
| `click` | 左键在同元素按下并抬起 |
| `mouseover` / `mouseout` | 指针进入 / 离开元素 |
| `focus` / `blur` | 输入框获得 / 失去焦点 |
| `input` | 输入框编辑中 |
| `change` | 值提交（失焦 / 回车）且与聚焦时不同 |
| `keydown` / `keyup` | 按键（派发给焦点输入框，无焦点时派发给 `<body>`） |
| `submit` / `reset` | 表单提交 / 重置 |
| `toggle` | `<details>` 开合 |
| `close` | `<dialog>` 关闭 |

事件对象带 `type` / `target` / `currentTarget` / `x` / `y` /
`stopPropagation()` / `preventDefault()`；键盘事件另有 `key` / `code` /
`keyCode` / `ctrlKey` / `shiftKey` / `altKey` / `metaKey` / `repeat`。

## 内置按键与事件门控

页面级快捷键（滚动 / 缩放 / 退出）在派发给页面 JS **之后**才执行：任何
`keydown` 监听器调用 `event.preventDefault()` 即可接管该按键：

```html
<script>
  document.body.addEventListener('keydown', function (event) {
    if (event.key === 'Escape') {
      event.preventDefault(); // 接管 Esc：不再退出，改为业务逻辑
    }
  });
</script>
```

内置按键一览：

| 按键 | 动作 |
| --- | --- |
| 滚轮、`↑` / `↓` | 滚动 |
| `PageUp` / `PageDown`、`Home` / `End` | 翻页 / 行跳转 |
| `g` / `G` | 跳到顶部 / 底部（vim 风格） |
| `Ctrl` + `Home` / `End` | 跳到顶部 / 底部 |
| `Ctrl` + `=` / `+`、`-`、`0` | 放大 / 缩小 / 复位 |
| 左键拖选 / 右键拖选 | 文本选择 / 矩形选择 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 复制 / 剪切 / 粘贴 |
| `Tab` / `Shift+Tab` | 焦点循环 |
| `Esc` | 退出 |

## 定时任务

```html
<script>
  setInterval(function () {
    document.getElementById('clock').textContent = new Date().toString();
  }, 1000);
</script>
```

`setTimeout` / `setInterval` / `clearTimeout` / `clearInterval` 均可用，回调在
消息间隙被调度。

## 动态改 DOM

JS 对 DOM 的任何修改（`textContent` / `style` / `appendChild` / `innerHTML`
……）都会被记录为脏节点，引擎只重绘受影响的区域，无需重新解析 HTML：

```html
<script>
  var n = 0;
  document.getElementById('btn').addEventListener('click', function () {
    n += 1;
    var li = document.createElement('li');
    li.textContent = 'item ' + n;
    document.getElementById('list').appendChild(li);
  });
</script>
```
