# htui 与主流浏览器能力对比及差异清单

本文件主要回答两个问题：主流 Web 平台的能力，htui 支持到什么程度,htui 渲染
结果与浏览器的差异部分。

> 状态图例：✅ 支持 · ◐ 部分/近似 · ✗ 不支持 · — 无对应


# HTML 特性清单

## 1. 文档结构与元数据

| 标签    | htui | 说明                                         |
| ------- | :--: | -------------------------------------------- |
| `html`  |  ✅  | 文档根元素（解析为块级根容器）               |
| `head`  |  ✅  | 文档元数据容器（解析但不渲染，sink）         |
| `body`  |  ✅  | 文档主体内容（块级容器）                     |
| `title` |  ✅  | 设为终端标题，不渲染正文（sink）             |
| `base`  |  ✅  | 文档基准 URL：首个带 `href` 的 `<base>` 生效；相对资源路径（`script src` / `link href` / `img src` / JS `fetch`）按它解析；不渲染；`target` 不支持 |
| `link`  |  ✅  | 元素入 DOM（不渲染，可被 CSS/JS 寻址）；`rel=stylesheet` 经 `mem://` 资源层加载，`href` 相对路径按 `<base>` 解析；其余 rel 仅保留元素 |
| `meta`  |  ✅  | 元数据（解析但不渲染，sink）                 |
| `style` |  ✅  | 内嵌 CSS，参与级联                           |

# CSS 特性清单 (CSS Snapshot 2024)

## 1. 显示与定位
