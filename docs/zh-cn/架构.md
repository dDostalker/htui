# 架构

本文描述 htui 的渲染管线与线程模型。能力边界（支持什么 / 拒绝什么）见
[边界文档](边界文档.md)，与浏览器的逐项差异见[能力差异清单](能力差异清单.md)。

## 渲染管线

```
HTML 字符串 ──► html5ever 解析 ──► DOM（slotmap NodeArena）
                                        │
CSS 字符串 ──► cssparser ──► 规则表 ──► 级联（含 :hover / :focus）
                                        │
                                        ▼
                 盒生成 generation：styled DOM → 逐节点浅分类（GeneratedBox）
                 （normal / text / replaced 分类；几何阶段按 DOM 重走，
                   每节点每次布局恰好分类一次，不递归子树）
                                        │
                                        ▼
                 几何 geometry：按 BoxKind × OuterDisplay × FormattingContext 分派
                    ┌────────────┼────────────┐
                    ▼            ▼            ▼
                 flow        flex         table
                    └────────────┼────────────┘
                                        ▼
                 LayoutBox 树（已定位）
                                        │
                                        ▼
                 绘制 paint ──► 字符画布（Vec<Block>）
                                        │
                                        ▼
                 增量 diff ──► ANSI 转义序列 ──► 终端
```

四层 `html → tdom → layout → tui` 不可破坏；generation / geometry 把盒分类
（`BoxKind` × `OuterDisplay` × `FormattingContext` 三轴）与具体布局算法
（flow / flex / table）解耦。

## 线程模型

引擎像浏览器一样多线程，每条线程职责单一：

| 线程 | 职责 |
| --- | --- |
| 输入循环（主线程） | `event::poll`、纯 UI 状态机（滚动 / 缩放 / 焦点 / 拖选）、把 DOM 写打包为 `ScriptMsg`。**永不执行 JS** |
| 脚本线程 | 独占 Boa 引擎与 live DOM；执行事件派发、宿主函数、定时器、fetch 微任务；维护 hover 状态机 |
| 渲染线程 | 级联 → 重排 → 重绘 → ANSI diff 输出；对命令做合并（`DrainedBatch`） |
| 命中测试线程 | 消费渲染线程发布的几何快照，构建共享 `HitMap` |

线程间通信：

```
输入循环 ──ScriptMsg──► 脚本线程 ──ScriptResponse（cmds / dirty / hovered）──► 输入循环
输入循环 ──RenderCmd──► 渲染线程 ──Arc<Geometry>──► 命中测试线程 ──HitMap──► 输入循环 + 脚本线程
```

关键性质：

- **宿主函数阻塞只拖住脚本线程**——滚动、退出、拖选照常（Tauri 式解耦）；
- 页面级快捷键走 key gate：先派发 `keydown` 给脚本线程，`preventDefault()`
  则内置行为让位；超时（脚本线程忙）则照常执行内置行为；
- JS 改 DOM 产生脏节点集合，随 `RenderArena` 到渲染线程——**只重绘受影响
  区域**，无需重新解析 HTML。

## 渲染合并与增量重绘

1. **值未变不渲染**：`el.textContent = v` 与当前值相同时直接短路；
2. **命令合并**：快照类命令（重排 / 重绘 / arena）只保留最后一个，输入与
   选择类保序，hover 增量叠加——DOM 变更与高亮增量都不丢失；
3. **区域重绘**：脏节点沿 DOM 找到最近的有盒祖先，rect 新旧一致（改动不涉
   及几何）时只重绘该矩形，否则回退全量；
4. **hover 增量**：单独的 hover 变化只重绘新旧目标区域并集；样式表没有
   `:hover` 规则时零绘制。

## 资源与会话

每个 `Session` 持有私有的 `mem://` 内存注册表（见
[3.0资源](教程/3.0资源.md)），安装到渲染线程与脚本线程。并行会话互不可见。

## 安全模型

- 全程无 `unsafe`；
- 页面 JS 受运行时限制：递归深度与循环迭代均有预算，死循环抛 JS 错误而非
  挂死脚本线程（挂死会导致鼠标消息在无界通道上堆积）；
- 图片解码有尺寸与分配上限（防解压炸弹）；SVG 栅格化在独立路径中执行；
- 资源层不触达文件系统与网络——文档能看见的字节全部由宿主显式注册。

注意：Boa 引擎与宿主代码运行在同一进程内，htui 提供的是**防挂死 / 防资源
失控**的健壮性边界，不是进程级安全沙箱。
