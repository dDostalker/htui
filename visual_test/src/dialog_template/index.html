dialog / template

A dialog is a framed box: hidden while `open` is absent, shown once it is present (browser UA default border). A form[method=dialog] submit button closes its dialog natively.

This dialog is open: it renders as a bordered block (UA default).

Click the [ Close ] button — form[method=dialog] removes the `open` attribute and fires a `close` event (see the status line).

I was hidden — JS opened me with setAttribute('open', '').

This one stays closed forever (no `open`, no JS toggling).
