Font Style Visual Test

Renders bold, italic, underline and line-through independently and combined. (SGR effects require interactive mode — `--dump` only verifies the structure.)

1. Baseline (no style)

plain text — control row, no SGR flags applied.

2. Single style per row

Bold weight only — font-weight: bold.

Italic only — font-style: italic.

Underline only — text-decoration: underline.

Strikethrough only — text-decoration: line-through.

3. Two-style combinations

Bold + Italic.

Bold + Underline.

Bold + Strikethrough.

Italic + Underline.

Italic + Strikethrough.

Underline + Strikethrough (single declaration).

4. Three-style combinations

Bold + Italic + Underline.

Bold + Italic + Strikethrough.

5. All four styles at once

Bold + Italic + Underline + Strikethrough.

6. Combined text-decoration syntax

Single rule: text-decoration: underline line-through.

7. Inheritance from parent

First child — should inherit bold from parent div.

Second child — also inherits bold.

Nested child — inherits BOTH bold (grandparent) and italic (parent).

8. Override on child

Child clears parent's bold (font-weight: normal).

Child keeps parent bold and adds italic.

9. Multiline span impact

Bold on a long paragraph that should wrap inside the terminal width. The bold weight flag should persist across every wrapped line of the same paragraph until the span ends. The batch renderer groups adjacent cells with the same style, so a long bold sentence produces only one opening SGR (1m) and one closing SGR (0m) per visible batch.

Italic on a long paragraph that should also wrap. Same batching rule applies — the style flag stays active across line breaks within the element.
